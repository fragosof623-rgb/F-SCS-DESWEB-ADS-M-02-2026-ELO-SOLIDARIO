Hospedagem e domínio

Onde o site está publicado hoje e quais opções a equipe avaliou para hospedagem e domínio.

Página em construção. Os valores de cada plano serão pesquisados nos sites oficiais e inseridos com a data da consulta.

Como o site está publicado hoje

O código fica no GitHub e é publicado no Railway. Como o site tem um servidor Node.js (que faz o EcoBot funcionar), a hospedagem precisa executar aplicações Node — uma hospedagem só de arquivos estáticos não seria suficiente.

Comparativo de hospedagem

Opções de hospedagem avaliadas
Serviço Roda o servidor Node (EcoBot)? Custo Observação
Railway Sim A pesquisar Opção usada hoje; publica a partir do GitHub.
Render Sim A pesquisar Também publica a partir do GitHub.
GitHub Pages Não A pesquisar Só arquivos estáticos: o site abriria, mas o EcoBot não funcionaria.

Domínio
